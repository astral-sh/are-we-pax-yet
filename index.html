Are we pax yet? 📦

What is pax?

The POSIX.1-2001 pax tar format extends the older ustar format to support features such as long paths and UTF-8 filenames.

What are source distributions?

Source distributions (sdists) are archives of a Python project's source code and build metadata. The sdist specification requires pax-format .tar.gz archives.

What is this list?

How do I create a pax sdist?

Python 3.8 made pax the default for tarfile. Python-based build backends such as setuptools inherit that default. Flit, Hatchling, and poetry-core select pax explicitly. (Python documentation)

These Rust-based build backends also default to pax.

  • uv 0.13 and later with the uv_build backend. (uv release notes)
  • maturin 1.14.0 and later. (maturin release notes)
