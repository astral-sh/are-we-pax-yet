Are we PAX yet? 📦

What is PAX?

PAX is the POSIX.1-2001 tar format. It extends the older ustar format to support features such as long paths and UTF-8 filenames.

What are source distributions?

Source distributions (sdists) are archives of a Python project's source code and build metadata. The sdist specification requires PAX-format .tar.gz archives.

What is this list?

The wheel shows the latest sdists from the $total most-downloaded projects on PyPI that have an unyanked sdist in their latest release. Each wedge represents one project, ordered clockwise by total downloads over 30 days, starting at the top.

  • Green packages ($pax_percent) with a 📦 use PAX or plain ustar headers.
  • Yellow packages ($gnu_percent) use GNU-style tar headers.
  • Uncolored packages ($unreadable_percent) have unreadable tar archives.
  • Magenta packages ($other_percent) use another archive format.

A PAX writer can emit plain ustar headers when no extensions are needed, so both count toward the total in the center of the wheel. Download the results as JSON.

How do I create a PAX sdist?

Check your build backend's sdist format. If you write the tar archive yourself with Python's tarfile, use tarfile.PAX_FORMAT.
